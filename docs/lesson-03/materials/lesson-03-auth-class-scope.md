# 第3课：认证、授权与班级材料

本文依据课程网站公开的第3课“本课目标与范围”整理，供复习课程范围与角色边界使用；这是整理版，不是课件逐字转录。

## 本课处理什么

本课让教师和学生登录，并把材料限制在各自班级。教师可以上传、查看和下载本班材料；学生可以查看和下载本班材料，没有上传权限。没有登录时，受保护接口不能返回材料标题或正文。

## 班级从哪里来

账号固定属于一个班级。查询列表、打开详情或下载材料时，系统使用登录会话中的班级信息；请求自己附带的班级编号不能改变用户可访问的范围。页面隐藏上传按钮只改善操作体验，真正的权限判断仍由服务端完成。

## 材料入库到哪一步

第3课只接收 .txt 和 .md 文本文件，并把原文件与正文保存下来，使本班成员刷新后仍能打开。它还没有实现文本切分、知识检索或问答；这些属于第4课的内容。PDF、Word、图片解析和在线编辑也不在这部分范围内。
