# 功能与处理流程

CampusClaw 将课程资料、学习助手、技能和工具连接在一起，服务教师的教学配置和学生的日常学习。

## 教师配置

教师上传讲义，为助手设置角色说明，并选择可使用的资料和技能。需要外部工具时，在工具接入页登记 MCP 服务、发现工具，再将工具绑定到相应技能。教师还可以签发邀请码，供本班教师和学生注册。

## 学生使用

学生选择讲义问答、解题引导或复习整理应用，选择提问模板后开始会话。回答逐段显示，问题和回答保存在个人会话中；涉及课程资料时，可查看相应出处。

## 一次提问的处理过程

1. **确认身份与范围**：服务端读取登录用户、所属班级以及当前助手配置。
2. **选择技能**：从已绑定、已启用的技能中匹配问题，选取匹配词最多的一项。
3. **检索资料**：在助手绑定的本班讲义中查找相关片段，结合关键词和向量结果排序。
4. **组装消息**：将角色说明、技能正文、已有对话、本轮问题、模板文字与相关资料组合为模型输入。
5. **按需调用工具**：向模型提供所选技能绑定的工具定义，检查模型给出的参数，执行工具并回传结果。
6. **显示并保存回答**：将模型生成的文字逐段传给页面，保存完整内容及资料引用。

## 主要实现

| 模块 | 功能 |
| --- | --- |
| 账号与权限 | 邀请码注册、登录退出、教师与学生角色、本班资料访问 |
| 讲义管理 | TXT/Markdown上传、正文查看、原文件下载、切片与索引 |
| 知识检索 | 关键词、向量和混合检索，材料范围筛选与出处展示 |
| 学习助手 | 三个内置应用、角色配置、预置提问模板、连续会话 |
| 技能管理 | 文本文件导入、技能编辑、触发条件匹配、助手绑定 |
| 工具接入 | MCP服务登记、工具发现、技能工具绑定、调用状态展示 |
| 流式交互 | 回答增量显示、工具状态更新、已生成内容保存 |
