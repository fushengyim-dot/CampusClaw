# 项目开发与验收记录

本仓库保留真实Git提交历史及OpenSpec设计、实施任务。它记录项目改动，不包含Codex对话记录。早期多项实现曾一次性提交；本次补交此前未提交的工作，不伪造逐日或逐课提交。

## 开发流程

1. 整理课程要求，建立OpenSpec的proposal、design、spec、tasks。
2. 第1—2课建立项目基础和认证、资料上传设计；早期提交见Git历史。
3. 第3课实现教师/学生会话、班级隔离、资料上传下载与数据库迁移。
4. 第4课实现关键词、向量、混合检索和来源引用。一次真实材料检查获准发送1段、实际发送3段，因此该次验收失败；后续增加数量上限控制及回归测试，失败历史保留。
5. 第5课加入三个课程应用、预置提问模板、助手与文本Skill配置、多轮会话和流式回答。
6. 第6课加入独立MCP服务、工具发现、绑定、参数检查、工具结果回传及调用摘要。
7. 后续补充教师/学生邀请码注册、技能文件上传、外部HTTPS MCP登记；修复工具状态显示、工具回答逐段输出和中断保存。
8. 按原作业五题整理报告。用户提供的代码截图用于解释实现；实际页面运行与真实模型验证分别记录，不把代码图当作实际请求抓包。

- 课堂来源核对版材料已保存绑定；关键词检索和跨班隔离检查通过。该材料没有就绪向量，真实语义检索闭环未通过。
