# 修复工具会话状态与正文流式

## Why
复验发现会话前端忽略工具事件，后端在全部工具与模型轮次完成后才返回整段正文。需兑现第6课已约定的工具可见状态及第5课逐段回答体验。

## What Changes
- SSE响应先发meta，再及时发送工具事件，最后逐段发送正文。
- 工具决策最多3轮、工具执行最多4次；决策完成后增加一次禁止工具调用的正文流式请求，总模型请求最多4次。即使决策首轮未提议工具，工具候选路径仍为一次决策加一次正文请求；无工具候选的普通问答保持一次请求。
- 会话页面显示工具名称和中文状态，结束后保留本轮状态直到切换会话或提交新问题。
- 中断时保存已生成正文，失败提示脱敏；不把整段答案事后拆分冒充流式。

## Impact
仅本项目会话前后端、测试与记录。无数据库迁移，不变更工具权限或现有材料绑定。真实课程模型兼容性与额度验收保持另行授权，本次只做本机测试。
