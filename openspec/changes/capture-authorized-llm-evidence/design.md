# Design
A config file selected by CAMPUSCLAW_CAPTURE_CONFIG activates a shared recorder. The authenticated handler attaches a case only for the configured teacher/class/conversation, question, template, agent prompt, skill and unique material. The HTTP wrapper rejects unscoped requests when enabled. Exclusive per-case attempt directories durably consume budgets before network access (A:1 embedding+1 chat; B:1 embedding+4 chat+4 tools). A failed/incomplete attempt prevents later calls for that case. The raw response body is teed as Read is called, preserving streaming; SSE DONE or JSON EOF determines completeness. Metadata excludes all headers except Content-Type/Accept. Files and hashes remain local. Recording disabled returns normal transport unchanged. Local httptest tests cover transport behavior without calling an external provider. The dedicated capture mode is disabled by removing its environment setting and restarting the service.

Capture material identifiers, Unicode length and SHA-256 are configuration values, not baked-in acceptance data. Configuration rejects missing material fingerprints and duplicate conversation scopes. Non-success HTTP responses are drained through the same bounded recorder before returning to callers that may only inspect status; they remain failed attempts. Configuration and output belong in ignored private runtime paths.
