# 第5课：提示词、AI技能与流式会话

## Why

第4课已有按班材料检索与一次性问答，但缺少教师可配置的智能体、技能路由、本人私有的多轮会话与逐段输出。第5课把这些能力增量接到现有登录、班级和知识库之上。

## What Changes

- 为会话、消息、智能体配置与技能/材料绑定增加不可变的向前迁移；保留已有数据与旧迁移。
- 教师可维护本班智能体、技能文件及绑定；学生仅能选择本班启用智能体。
- 首页提供讲义问答、解题引导、复习整理三个内置应用；学生可选提问模板与教师角色提示分开。
- 会话固定智能体且仅本人可读；提问在服务端落库后进入有界上下文。
- 技能由自定义文本格式解析，确定性路由；知识检索仅使用智能体绑定材料，答案通过SSE流式返回并保存引用。
- 由代码注解生成OpenAPI并提供Swagger页面；前端使用fetch提交并解析SSE。

## Capabilities

### New Capabilities
- `prompt-skills-streaming`: 第5课智能体、技能、会话、消息、受限检索、流式回答与接口文档。

### Modified Capabilities
- `knowledge-retrieval`: 复用既有检索服务，但第5课只检索智能体绑定材料，并允许无命中时按角色提示继续回答。

## Non-goals

- 不实现第6课MCP工具服务器与模型工具调用。
- 不发送任何新课程模型请求；只用本地stub/模拟和本机服务检查。
- 不处理第4课真实材料验收偏差，不删除或重置已有数据库/上传文件。
- 不公开部署、不改其他项目、不更新全局Skill。

## Sources and limits

依据老师第5课公开页面：scope、apply、session、skill-model、route、stream、answer。2026-10-28通过PowerShell读取均返回HTTP 200。第4课canonical spec和真实材料越权范围记录继续有效；本变更不声称消除该验收失败。
