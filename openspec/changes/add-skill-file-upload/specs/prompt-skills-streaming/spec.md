## ADDED Requirements

### Requirement: 课程技能纯文本文件导入
系统 MUST 向教师提供课程技能文本文件选择入口，支持单个 UTF-8 `.txt` 或 `.md` 文件，并把读取内容载入现有技能编辑器后由教师确认保存。

浏览器 MUST 在保存前拒绝不支持的扩展名、无效 UTF-8 和超过8000个 Unicode 字符的文件；失败时 MUST 显示可读原因、保留原有草稿且不得提交保存请求。服务端 MUST 继续执行已有技能格式、字段、权限、长度及班级唯一性校验，不能信任浏览器检查结果。

文件内容 MUST 作为纯文本处理；系统 MUST NOT 执行其代码、脚本或命令。该入口只承诺支持课程自定义纯文本格式，不声称兼容标准 `SKILL.md` 目录、附件或归档包。

#### Scenario: 导入有效课程技能文件
- **WHEN** 教师选择一个符合课程格式的 UTF-8 `.txt` 或 `.md` 文件
- **THEN** 浏览器将其完整文本载入技能编辑器，教师确认后复用现有保存接口

#### Scenario: 拒绝不支持的文件
- **WHEN** 教师选择其他扩展名、无效UTF-8或超长文件
- **THEN** 页面显示可读错误、保留原草稿且不发送保存请求

#### Scenario: 服务器拒绝格式错误的文本
- **WHEN** 文件可读但内容不符合课程技能格式或教师权限
- **THEN** 现有服务端校验拒绝保存且不绕过权限或字段检查
