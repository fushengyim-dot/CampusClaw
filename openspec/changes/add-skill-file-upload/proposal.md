# 技能文本文件上传

## Why

平台作业要求支持上传技能。第5课已经规定技能使用课程自定义纯文本格式并由服务器校验，但教师页面目前只能在大文本框中粘贴或编辑，不能从文件选择器选取技能文件。

## What Changes

- 教师可以选择 UTF-8 编码的 `.txt` 或 `.md` 技能文件，将文件内容载入现有编辑器并提交。
- 保持现有课程格式、字段校验、班级内唯一名称、8000字上限和教师权限；不宣称兼容通用 `SKILL.md` 目录或资源包。
- 无效编码、扩展名或超长文件显示可读错误，不提交保存请求。

## Non-goals

- 不新增技能解析格式或后端存储结构。
- 不执行上传文件中的程序、脚本或外部工具。
- 不上传多文件目录、压缩包、图片或可执行文件。

## Evidence boundary

课程第5课规约已定义自定义文本格式和长度限制；本变更补齐该格式的文件选择入口。标准 Agent Skill 目录兼容性不属于本次声明。
