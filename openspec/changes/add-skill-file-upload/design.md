# Design: 技能文本文件上传

## Decisions

1. 复用现有教师技能编辑和保存 API，浏览器通过文件选择器读取一个 UTF-8 `.txt` 或 `.md` 文件，载入已有文本编辑器；教师确认后仍按现有 JSON `source_text` 提交。
2. 读取时使用严格 UTF-8 解码，拒绝无效字节；限制文件扩展名且最多8000个 Unicode 字符。后端现有解析器继续作为权威校验，不信任浏览器校验。
3. 上传文件只作为课程技能描述文本，不执行内容。保持当前权限、审计与班级隔离。
4. 读取或校验失败时展示错误，不改变当前技能草稿、不调用保存 API。

## Risks

- 文件扩展名不能证明内容安全，因此只把内容作为普通文本读取并交给现有字段解析器。
- 浏览器端字符计数仅用于尽早提示；服务端校验仍决定是否接受。
