# 接入外部 HTTPS MCP 服务器

## Why

课程作业要求支持外部工具与 MCP。现有功能只允许连接项目自带的本机只读工具服务，教师无法登记课程以外的 MCP 服务器。

## What Changes

- 教师可以为本班登记外部 HTTPS Streamable HTTP MCP endpoint 和服务器专用 Bearer token，并显式点击连接、发现工具。
- 连接与调用兼容 MCP `2025-11-25` 的 JSON 或 SSE 响应及可选会话标识；仅支持静态 Bearer 凭证，不实现 OAuth、stdio 或旧版 HTTP+SSE。
- 外部地址必须是 HTTPS 公网目的地；拒绝私网、回环、链路本地、保留地址和非公网DNS解析；解析后固定本次连接的公网地址，禁止代理与重定向。
- 保留现有工具结构校验、技能绑定、调用额度、结果限制、班级隔离和审计边界。

## Non-goals

- 不连接任何真实第三方MCP服务作为本变更的实现验收；仅以本机合成服务器/stub测试。
- 不提供任意命令执行、stdio启动、本地IP白名单或 OAuth 授权流程。
- 不自动信任刚发现的工具；教师仍需显式绑定到技能。

## Evidence boundary

课程作业要求来自用户提供的作业描述。协议行为依据MCP `2025-11-25`官方传输和安全文档。支持范围有限，不代表兼容所有MCP服务器。
