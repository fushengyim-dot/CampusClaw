# CampusClaw

面向教师与学生的 AI 课程学习平台。围绕课程讲义，把资料检索、连续问答、学习提示和工具调用放在同一个工作空间中。

## 可以做什么

- **三个学习应用**：讲义问答帮助查找课程依据，解题引导提供下一步提示，复习整理生成提纲与自测问题。
- **提示词模板**：学生可选择概念解释、实操排查、复习提纲等提问方式；教师可调整助手的角色说明。
- **课程知识库**：上传 TXT 或 Markdown 讲义，支持关键词、向量和混合检索；回答可附资料出处。
- **可配置技能**：内置技能样板，支持导入文本技能文件，并为助手绑定适用的技能与资料。
- **MCP 工具接入**：连接内置课程工具或外部 HTTPS MCP 服务，为技能绑定工具，查看调用状态。
- **教师与学生协作**：通过邀请码注册，按班级隔离资料；支持连续会话、逐段显示回答和历史记录。

## 使用方式

教师上传讲义，配置助手使用的资料、技能与工具，并为本班成员签发邀请码。学生注册后选择学习应用和提问模板，即可开始会话。

关键词搜索在本机完成。向量检索需要嵌入服务，AI 回答需要对话模型；使用这些功能时，问题及相关资料可能发送到配置的模型服务，并产生费用。上传讲义不会自动发送全文进行向量化。

## 本地运行

当前启动脚本面向 Windows、PowerShell 和 Docker Desktop，包含 F 盘路径与指定 Go 工具路径配置。首次部署请先阅读[运行说明](docs/LOCAL_SETUP.md)，确认环境与模型配置。

启动后访问 **http://127.0.0.1:8080**。

## 技术组成

| 部分 | 技术 |
| --- | --- |
| 页面 | React、TypeScript、Vite |
| 后端 | Go、HTTP API、SSE 流式响应 |
| 数据 | MySQL、Qdrant、本地文件存储 |
| 部署 | Docker Compose、NGINX |
| 工具 | MCP Streamable HTTP |

## 使用范围

- 讲义支持 UTF-8 编码的 `.txt`、`.md` 文件，单个文件不超过 5 MiB。
- 技能导入采用本项目的文本格式。
- 外部 MCP 支持 `2025-11-25` Streamable HTTP、HTTPS 公网地址和静态 Bearer 令牌。
- 第三方模型与 MCP 服务的兼容性取决于其接口实现，需要针对所选服务验证。
